# 念念听写 · 微信小程序（体验版零备案路线）

家庭内使用的听写工具小程序端。后端就是家里 NAS 上的听写服务（本仓库的 Next.js
应用），不迁云、不备案、不配域名，走微信「体验版」长期给家人使用。

## 首次配置（开发者本人，一次性）

1. **服务器地址**：复制 `config.local.example.js` 为 `config.local.js`，把
   `baseUrl` 改成 NAS 的局域网地址（该文件已被 gitignore，不会进公开仓库）。
2. **AppID**：注册小程序后（mp.weixin.qq.com，个人主体，免费），把
   `project.config.json` 里的 `"appid": "touristappid"` 换成你的 AppID。
3. **微信开发者工具**：安装 Windows 稳定版，导入本目录（`miniprogram/`），
   用微信扫码登录。本项目已设置 `urlCheck: false`，工具内可直接访问局域网
   http 地址。

## 上传体验版（每次发版）

1. 开发者工具右上角「上传」→ 填版本号和备注。
2. mp.weixin.qq.com → 管理 → 版本管理 → 开发版本 → 「选为体验版」。
3. 把体验版二维码发给已添加为体验成员的家人。

## 家人首次使用（每台手机一次性）

1. 手机连家里 WiFi（听写场景本来就在家）。
2. 扫体验版二维码打开小程序。
3. 右上角胶囊菜单 → 「开发调试」→ 打开 → 重启小程序。
   **这一步必须做**：体验版默认校验服务器域名白名单，而家里的局域网地址
   没有也无法备案；打开开发调试后跳过域名校验。
4. 如果手机装了代理 App，把内网网段加进绕过列表，否则请求会被代理吞掉
   （Web 版时代踩过的真实坑，小程序同样适用）。

## 后台配置（mp.weixin.qq.com，一次性）

- 成员管理 → 体验成员：添加家人微信号（上限 15 人）。
- 设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引：声明
  「选中的照片或视频信息」，否则选照片/拍照接口会被拒绝。
- 不需要：服务器域名配置、ICP 备案、类目审核（不发布正式版就不触发）。

## 已知边界（体验版路线的代价）

- 不能被搜索、不能正式分享给非体验成员；想给外人用必须走备案 + 发布。
- 界面带「体验版」角标和 vConsole 按钮（开发调试开启后）。
- 长期零活跃的账号可能被微信回收，偶尔上传个新版本保持活跃。
